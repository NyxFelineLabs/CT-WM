# Recorded results and scope

All numbers below come from saved experiments; publishing the repository did
not retrain or rerun the full experiments. Machine-readable aggregates are in
[`results/`](../results). Their hashes are in
[`source_provenance.json`](../results/source_provenance.json).

Persistence predicts the next RSRP as the latest observed RSRP and has no
trainable parameters. Reductions use the full-precision persistence errors;
negative values indicate worse errors. All methods use the same target set.
Parameters are in millions (M). Neural-model MC8 latency at batch 256 is
1.44/1.41/1.03/2.17 ms per sample for L32/no-z/L16/L64, respectively;
this is throughput amortization, not single-request latency.
Full-precision data remain in the CSV files.

11,867 common targets from two held-out files; RSRP target head, physical units,
prior-only testing. The full-KPI decoder used for rollouts has different errors:
RSRP MAE/RMSE 0.313174/0.444158 dB, SINR 0.426774/0.594986 dB. Its eight-step RSRP
RMSE reaches 2.556014 dB. Target-head accuracy does not certify rollout fidelity.

## Long-horizon extensions — a different environment

The following is a Python-link PRB/MCS task, not the frozen-model environment
above. Each method uses 16 starts ×3 feedback seeds ×128 steps; changes are
relative to paired own-feedback OLLA with fixed initial PRB.

| Method | SE change/% | PRB saving/% | Worst-trajectory change/% | Mean/ms | P99/ms |
|---|---:|---:|---:|---:|---:|
| OLLA | +0.00 | +0.00 | +0.00 | 0.29 | 0.44 |
| Pure PRB | −69.23 | +30.56 | −77.99 | 5.45 | 9.17 |
| Greedy PRB + OLLA | −30.14 | +39.73 | −37.43 | 0.31 | 0.51 |
| Joint SAC | −25.44 | +34.76 | −33.77 | 0.98 | 1.42 |

| Only MCS, initial PRB | +0.104 | +0.00 | −5.641 | 5.891 | 9.848 |

The last two rows are a separate matched ablation run. OLLA's zero follows from
its definition as reference, not zero absolute risk. CT-WM consumes 0.57% more
PRB in the main condition; simultaneous quality/resource improvement is not
established. The eight-method main run is in `rhc_main.csv`; it is not the earlier
five-method run generated by `e2_experiment.py evaluate`.

Matched predictor follow-up: learned forecasting gives SE +0.503%, PRB saving
−0.603%, mean 5.170 ms; persistence gives +0.557%, +0.067%, 1.643 ms. This does
**not** establish incremental closed-loop control benefit from the learned
predictor. Shared gate/reward thresholds originally selected for learned forecasts
were not symmetrically retuned for persistence.

Multi-SNR follow-up retains adverse outcomes: CT-WM's worst trajectory is
−33.766% at 10 dB and −22.553% at 15 dB. These are shifts of the SINR proxy, not
independent physical signal/interference decompositions. The compound `no_calib`
variant changes stress paths as well as intervals. A temperature-only audit on
6,144 paired states finds **zero action differences**, with 50%/95% coverage
35.107%/97.738%. Offline mixture calibration does not certify this other mapping.

No universal safety, real E2 interoperability, RL convergence, independent-network
generalization or preemptive 15 ms hard deadline is claimed. These boundaries apply to the recorded experiment results.
